# multimacd ChangeLog

Changes of `multimacd`, the process that shares the radio module
(RPI-RF-MOD, HmIP-RFUSB) between rfd and the HmIP server. Newest version
first.

Changes not yet released are collected under `Unreleased` and get the
version and date with the next version bump (`version.sh`).

## Unreleased

* add the option `-v` / `--version`, which prints the version of multimacd and
  of the libelvutils it uses.
  ([#294](https://github.com/OpenCCU/OpenCCU-Base/pull/294), @jens-maus)

## 1.2.0 (2026-01-15)

* first version with a version string (`version.sh`). (@cn-eq3)

## Older versions
