# SetInterfaceClock ChangeLog

Changes of `SetInterfaceClock`, the tool that sets the clock of the radio
interfaces. Newest version first.

Changes not yet released are collected under `Unreleased` and get the
version and date with the next version bump (`version.sh`).

## 1.0.0 (2026-11-02)

* first version with a version string (`version.sh`): `-v` / `--version`
  prints it together with the versions of libXmlRpc and libelvutils.
  SetInterfaceClock no longer links libhsscomm and libxmlparser, which it
  does not use.
  ([#294](https://github.com/OpenCCU/OpenCCU-Base/pull/294), @jens-maus)

## Older versions

Changes of earlier versions are only recorded in the git history of this
repository.
