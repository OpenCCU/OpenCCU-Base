# HmIP server

The HmIP server (`HMIPServer`) is the Java service of the CCU that handles Homematic IP devices.

The HmIP server is **closed source**: its source code cannot be published and is therefore not part of OpenCCU-Base. Only its binaries and runtime files are provided here.

## Files

- `opt/HMServer/HMIPServer.jar` - the HmIP server.
- `opt/HmIP/` - additional runtime files of the HmIP server (e.g. `hmip-copro-update.jar`, `legacy-parameter-definition.config`).

## Issues

Please report problems with the HmIP server in the OpenCCU issue tracker: https://github.com/OpenCCU/OpenCCU/issues
